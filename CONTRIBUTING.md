# Contributing to MGE Finder

Thank you for your interest in contributing to MGE Finder!

## Development Setup

1. Fork the repository
2. Clone your fork:
   ```bash
   git clone https://github.com/your-username/MGE_finder.git
   cd MGE_finder
   ```
3. Create a branch for your changes:
   ```bash
   git checkout -b feature/your-feature-name
   ```
4. Make your changes
5. Test your changes thoroughly
6. Commit with clear messages:
   ```bash
   git commit -m "Add feature: description"
   ```
7. Push to your fork:
   ```bash
   git push origin feature/your-feature-name
   ```
8. Create a Pull Request

## Code Style

- Follow PEP 8 for Python code
- Use meaningful variable and function names
- Add docstrings to functions and classes
- Comment complex logic

## Testing

Before submitting a PR, ensure:
- All existing tests pass
- New functionality is tested
- Configuration examples are updated if needed
- Documentation is updated

## Documentation

- Update README.md if adding new features
- Add docstrings to new functions
- Update configuration examples if parameters change

## Reporting Issues

When reporting issues, please include:
- Description of the problem
- Steps to reproduce
- Expected vs actual behavior
- Environment details (OS, Python version, etc.)
- Relevant error messages or logs

## Questions?

Feel free to open an issue for questions or discussions.
